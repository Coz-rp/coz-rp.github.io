Setup

Installing a preset

Chat Completion presets import in seconds. You'll need SillyTavern connected to a Chat Completion source (OpenRouter, etc.).

  1. Download the preset .json above.
  2. In SillyTavern, open AI Response Configuration (the top-left sliders icon).
  3. Click the Master Import button and select the downloaded file.
  4. Pick the new preset from the dropdown, choose your model, and you're set.
